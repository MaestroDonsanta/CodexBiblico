¿Cómo obtener tu clave gratis en 1 minuto?

  1. Entra a Google AI Studio e inicia sesión con tu Gmail.
  2. Toca el botón azul "Get API Key" (Obtener clave).
  3. Selecciona "Create API Key" (Crear clave), cópiala.
  4. Pégala en el cuadro de texto de arriba y pulsa "Guardar".
